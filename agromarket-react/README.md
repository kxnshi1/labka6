# АгроМаркет — лабораторная работа №4

Дисциплина: Fullstack-разработка, 2 курс.

## Лабораторная 4 — вёрстка

В работе переделана структура страницы интернет-магазина «АгроМаркет» с использованием семантических HTML5-тегов, Flexbox, CSS Grid и mobile-first адаптивности. Логика поиска и загрузка товаров оставлена на React, данные берутся из `json-server`.

### Запуск

Окно 1:
```bash
cd agromarket-react
npx json-server --watch db.json --port 3001
```

Окно 2:
```bash
cd agromarket-react
npm install
npm run dev
```

После запуска открыть `http://localhost:5173`.

### Box model карточки (часть 1)
- content: зависит от ширины сетки и содержимого карточки;
- padding: 16px;
- border: 1px;
- margin: внешнего отступа у самой карточки нет, расстояние между карточками задаёт `gap: 20px`;
- `box-sizing: border-box` включён глобально, поэтому заданные размеры элемента учитывают padding и border.

### repeat(4, 1fr) на узком экране (часть 4)
При фиксированных четырёх колонках карточки начинают сильно сжиматься и макет становится неудобным для телефона. Поэтому в итоговой версии используется `repeat(auto-fit, minmax(220px, 1fr))`.

### auto-fit vs auto-fill (часть 4)
`auto-fit` подстраивает число видимых колонок под доступное содержимое и растягивает их, поэтому для каталога в этой работе выбран именно этот вариант.

### Адаптивность (часть 5)
| Ширина | Колонок | Где «Доставка» | Шапка |
|--------|---------|----------------|-------|
| 375 | 1 | под каталогом | столбик |
| 768 | 1–3 в зависимости от ширины карточек | под каталогом | ряд |
| 1280 | 3–4 в зависимости от фактической ширины области | справа | ряд |

### Семантика
Использованы `header`, `nav`, `main`, `section`, `aside`, `article`, `address`, `footer`. `ProductCard` оформлен как `article`, потому что отдельная карточка товара является самостоятельным содержательным блоком.

### Форма
Добавлены поля `text`, `email`, `tel`, `number` с `min="10"`, `date`, `textarea` и `required`. Валидация выполняется средствами HTML5.

### Что проверено
- поиск по каталогу;
- добавление товара увеличивает счётчик корзины;
- адаптивная шапка и каталог;
- форма не отправляется при неверном email или количестве меньше 10 кг;
- после корректной отправки появляется сообщение и форма очищается.

### Вопросы для защиты — краткие ответы
1. `section` группирует тематический раздел страницы, а `article` представляет самостоятельный законченный блок. Карточка товара подходит под `article`.
2. `main` обозначает главное содержимое страницы и обычно используется один раз, а внутри него может быть несколько `section`.
3. `box-sizing: border-box` включает padding и border в указанную ширину элемента.
4. Flexbox удобен для расположения элементов в одном направлении, а Grid — для двумерной сетки каталога.
5. `repeat(auto-fit, minmax(220px, 1fr))` автоматически подбирает количество колонок, сохраняя минимальную ширину 220px и деля свободное место.
6. Mobile-first означает, что сначала задаются стили для маленьких экранов, а затем через `min-width` добавляются возможности для больших.
7. `label` связывает подпись с полем, а `type="email"` включает встроенную проверку формата email.

## Лабораторная 5 — подключение Express API

Frontend теперь получает товары не от json-server, а от `http://localhost:3000/api/products` и отправляет форму на `POST http://localhost:3000/api/orders`.

Для запуска нужны два терминала:

**Терминал 1 — backend:**

```bash
cd agromarket-server
npm install
npm run dev
```

**Терминал 2 — frontend:**

```bash
cd agromarket-react
npm install
npm run dev
```

`json-server` из лабораторной 3/4 для лабораторной 5 запускать не нужно.
